---
title: "Create a skill from chat"
description: "Turn a useful Harness chat into a reusable skill"
---

Do the work once in chat before you turn it into instructions.

## Turn a useful chat into a skill

1. Finish the task in chat and keep the thread open.
2. Ask in plain English: `Turn what we just did into a reusable skill in this workspace`.
3. Harness writes a `SKILL.md` file inside your workspace (for example `.opencode/skills/<name>/SKILL.md`). The file stays on your machine.
4. Give the skill a clear name if Harness asks, then let it confirm what it saved.
5. Use it later by name in chat, or describe the same kind of task and let Harness trigger it when it matches.

## Other ways to create a skill

- **From the Library**: open `Settings` > `Library`, filter to `Skills`, and click `Add skill`.
- **By hand**: create a folder under `.opencode/skills/` with a `SKILL.md` file. Harness uses the same format as Claude Code and Claude Cowork.

## Change or share it

1. To refine it, ask for the change in chat, such as `Make the skill ask before sending email`, or edit `SKILL.md` directly.
2. To share it, copy the skill folder to a teammate or commit it to a repository you both use.
