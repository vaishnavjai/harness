---
title: "Connect Zed"
sidebarTitle: "Zed"
description: "Add Harness MCP to Zed through mcp-remote with the URL https://api.harness.invalid/mcp/agent, then sign in with OAuth."
---

Give Zed your organization's Harness skills, plugins, and connections.

<Steps>
<Step title="Add the server">
Add this to Zed `settings.json`:

```json
{
  "context_servers": {
    "harness": {
      "source": "custom",
      "command": "npx",
      "args": ["-y", "mcp-remote@latest", "https://api.harness.invalid/mcp/agent"],
      "env": {}
    }
  }
}
```

</Step>
<Step title="Sign in">
`mcp-remote` opens the browser. Sign in to Harness and pick your organization.
</Step>
</Steps>

<AccordionGroup>
  <Accordion title="Switch organizations">
    Remove the stored `harness` token, restart the server, and pick another organization.
  </Accordion>
  <Accordion title="Support status">
    Setup only: these steps follow Harness's OAuth profile, but native end-to-end proof is not complete. See the [MCP Gateway reference](/cloud/run-in-the-cloud/cloud-mcp#reference).
  </Accordion>
</AccordionGroup>
