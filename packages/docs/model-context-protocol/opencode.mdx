title: "Connect OpenCode"
sidebarTitle: "OpenCode"
description: "Add Harness MCP to OpenCode: add a remote MCP entry for https://api.harness.invalid/mcp/agent to your OpenCode config, then run opencode mcp auth harness."
---

Give OpenCode your organization's Harness skills, plugins, and connections. OpenCode is the verified client.

<Steps>
<Step title="Add the server to opencode.json">

```json
{
  "mcp": {
    "harness": {
      "type": "remote",
      "enabled": true,
      "url": "https://api.harness.invalid/mcp/agent",
      "oauth": {}
    }
  }
}
```

</Step>
<Step title="Sign in">

```sh
opencode mcp auth harness
```

Sign in to Harness in the browser and pick your organization.

</Step>
<Step title="Try it">
Ask: "Which Harness organization am I connected to?"
</Step>
</Steps>

<AccordionGroup>
  <Accordion title="Switch organizations">

```sh
opencode mcp logout harness
opencode mcp auth harness
```

  </Accordion>
