---

Give VS Code your organization's Harness skills, plugins, and connections.

<Steps>
<Step title="Add the server">
[Install in VS Code](vscode:mcp/install?%7B%22name%22%3A%22harness%22%2C%22type%22%3A%22http%22%2C%22url%22%3A%22https%3A%2F%2Fapi.harness.invalid%2Fmcp%2Fagent%22%7D) in one click, or run:

```sh
code --add-mcp '{"name":"harness","type":"http","url":"https://api.harness.invalid/mcp/agent"}'
```

</Step>
<Step title="Sign in">
Run `MCP: List Servers` > `harness` > `Start Server`, sign in to Harness, and pick your organization.
</Step>
<Step title="Try it">
Ask: "Which Harness organization am I connected to?"
</Step>
</Steps>

<AccordionGroup>
  <Accordion title="Manual config">
    Run `MCP: Open User Configuration`, or edit `.vscode/mcp.json` for one workspace:

```json
{
  "servers": {
    "harness": {
      "type": "http",
      "url": "https://api.harness.invalid/mcp/agent"
    }
  }
}
```

  </Accordion>
  <Accordion title="Switch organizations">
    Remove the stored `harness` token, start the server again, and pick another organization.
  </Accordion>
  <Accordion title="Support status">
    Setup only: these steps follow Harness's OAuth profile, but native end-to-end proof is not complete. See the [MCP Gateway reference](/cloud/run-in-the-cloud/cloud-mcp#reference).
  </Accordion>
</AccordionGroup>
