Two ways to fix it.

## Ask us to write it

[Email the team](https://github.com/vaishnavjai/harness/issues) with the feature you're trying to use and we'll write the page.

## Write it yourself

Harness docs live in the [harness repo](https://github.com/vaishnavjai/harness/tree/dev/packages/docs). Open a PR with a new `.mdx` page and we'll review it.
