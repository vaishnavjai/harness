Give Gemini CLI your organization's Harness skills, plugins, and connections.

<Steps>
<Step title="Add the server">

```sh
gemini mcp add --transport http harness https://api.harness.invalid/mcp/agent
```

</Step>
<Step title="Sign in">
Start `gemini`, run `/mcp auth harness`, sign in to Harness in the browser, and pick your organization.
</Step>
<Step title="Try it">
Ask: "Which Harness organization am I connected to?"
</Step>
</Steps>

<AccordionGroup>
  <Accordion title="Switch organizations">
    Remove the stored `harness` token, run `/mcp auth harness` again, and pick another organization.
  </Accordion>
  <Accordion title="Support status">
    Setup only: these steps follow Harness's OAuth profile, but native end-to-end proof is not complete. See the [MCP Gateway reference](/cloud/run-in-the-cloud/cloud-mcp#reference).
  </Accordion>
</AccordionGroup>
