sidebarTitle: "Codex"
description: "Add Harness MCP to Codex with one command: codex mcp add harness --url https://api.harness.invalid/mcp/agent, then codex mcp login harness."
---

Give Codex your organization's Harness skills, plugins, and connections.

<Steps>
<Step title="Add the server">

```sh
codex mcp add harness --url https://api.harness.invalid/mcp/agent
```

In the Codex desktop app, paste the URL in `codex://settings/connections` instead.

</Step>
<Step title="Sign in">

```sh
codex mcp login harness
```

Sign in to Harness in the browser and pick your organization.

</Step>
<Step title="Try it">
Ask: "Which Harness organization am I connected to?"
</Step>
</Steps>

<AccordionGroup>
  <Accordion title="Switch organizations">

```sh
codex mcp logout harness
codex mcp login harness
```

  </Accordion>
