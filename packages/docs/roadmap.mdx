Harness is a desktop app. Agents work on your own files, keep long-term memory on your machine, and reach only the model endpoints you configure.

<Info>
  **Live** means available today. **Partial** means supported with limitations.
</Info>

## The desktop app

| Capability | What it does | Status |
| --- | --- | --- |
| Desktop app for macOS, Windows, and Linux | A complete local-first workspace for agentic work. | Live |
| Local files and workspaces | Work directly with the files and repositories already on your computer. | Live |
| Bring your own model | Ollama, vLLM, llama.cpp and LM Studio on loopback, or hosted providers with your own keys. | Live |
| Long-term memory | An embedded Hindsight engine, supervised by the app and bound to loopback, retains and recalls across chats. | Live |
| Skills, plugins and MCP servers | Customize what your agent knows and which systems it can use. | Live |
| Audit log | Tool runs, terminal commands, file writes and network egress in a hash-chained log you can verify. | Live |
| Artifacts | Preview, edit, download, and reopen generated files without leaving the workspace. | Live |
| Built-in browser control | Let agents navigate, click, type, and capture pages in a browser that stays visible inside the app. | Live |
| Scheduled tasks | Run any prompt on a schedule. | Partial |
| Isolated sandbox workspaces | Run work in a separate Docker or microsandbox environment. | Partial |

## MCP spec compliance

Harness implements the [MCP authorization specification](https://modelcontextprotocol.io/specification/2025-06-18/basic/authorization) as an MCP client.

| Capability | What it does | Status |
| --- | --- | --- |
| OAuth 2.1 self-discovery | Connect to a compliant MCP server with just its URL: `WWW-Authenticate` challenge, Protected Resource Metadata (RFC 9728), Authorization Server Metadata (RFC 8414), and Dynamic Client Registration (RFC 7591). | Live |
| PKCE and resource indicators | PKCE (S256) enforced on all authorization flows, with RFC 8707 resource indicators on authorization and token requests. | Live |
| Manual client credentials fallback | Enter a client ID and secret for authorization servers that do not offer Dynamic Client Registration. | Live |
