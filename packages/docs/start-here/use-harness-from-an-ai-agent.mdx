This page lists the exact steps an agent needs to install Harness.

<Warning>
Don't use `npx harness`, `npm install harness`, `brew install --cask harness`, or any other package-manager name for Harness. Harness is distributed only through [GitHub Releases](https://github.com/vaishnavjai/harness/releases) and from source; packages with that name on public registries are different projects.
</Warning>

## Just me: install the desktop app

Free, no account needed.

| OS | Install |
|---|---|
| macOS | [Apple Silicon](https://github.com/vaishnavjai/harness/releases) or [Intel](https://github.com/vaishnavjai/harness/releases) `.dmg` |
| Windows | [x64](https://github.com/vaishnavjai/harness/releases) or [ARM64](https://github.com/vaishnavjai/harness/releases) `.exe` |
| Linux | [x64](https://github.com/vaishnavjai/harness/releases) or [ARM64](https://github.com/vaishnavjai/harness/releases) `.AppImage` |

These links always point to the latest stable release. Then [run your first task](/desktop-app/first-task).

## My team: set up Harness Cloud

1. [Sign up](https://app.harness.invalid?mode=sign-up) and name your team. That creates your organization. The first 5 seats are free.
2. Invite teammates in `Members` > `Add member`.
3. Share models in `AI Gateway` > `AI Providers` > `Add provider`.
4. Share a skill: `Plugin Directory` > `Create plugin` > `+ Skill`, add it to a Collection, and grant it to a team.
5. Everyone installs the desktop app and clicks `Joining a team? Sign in`.

Full walkthrough: [Team quickstart](/cloud/team-quickstart). For a headless, agent-run setup, follow [start.md](https://harness.invalid/start.md). It uses the `harness-bootstrap` CLI from `https://harness.invalid/install.sh`, which needs Node.js 20+ and doesn't install the desktop app.

## Inside my agent: connect the MCP Gateway

Server URL: `https://api.harness.invalid/mcp/agent`. Sign-in uses OAuth in the browser. You need a Harness Cloud account.

```sh
# Claude Code
claude mcp add --transport http harness https://api.harness.invalid/mcp/agent

# Codex
codex mcp add harness --url https://api.harness.invalid/mcp/agent
codex mcp login harness

# Gemini CLI
gemini mcp add --transport http harness https://api.harness.invalid/mcp/agent

# OpenCode
opencode mcp add harness --url https://api.harness.invalid/mcp/agent
opencode mcp auth harness
```

Other clients: [Connect Harness MCP](/start-here/connect-harness-mcp). It's working when your agent lists the `search_capabilities` and `execute_capability` tools.
