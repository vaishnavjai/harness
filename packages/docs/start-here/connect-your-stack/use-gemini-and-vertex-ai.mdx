---
title: "Use Gemini and Google Vertex AI"
description: "Connect Google Gemini to Harness with a Gemini API key, or through your own gateway in front of Google Vertex AI."
---

Harness works with Google's Gemini models. Paste a Gemini API key under `Settings > AI Providers > Connect provider` and choose `Google`, or point Harness at an OpenAI-compatible gateway that forwards to Vertex AI. Harness encrypts the key with your OS keychain.

## Choose your path

| You want | Use |
| --- | --- |
| Gemini for yourself, billed to your own Google AI Studio key | [Option 1: Gemini API key](#option-1-gemini-api-key) |
| Gemini through your own gateway in front of Vertex AI | [Option 2: Your own gateway](#option-2-your-own-gateway-in-front-of-vertex-ai) |

## Option 1: Gemini API key

1. Create an API key in [Google AI Studio](https://aistudio.google.com/apikey). Copy it once and keep it private.
2. In Harness, open `Settings` and choose `AI Providers`.
3. Click `Connect provider`.
4. Type `google` in `Filter providers by name or ID` and select `Google`.
5. Paste the key into the `API key` field and save.
6. Open the chat model picker and choose a Gemini model.

Usage is billed by Google to the account that owns the key.

## Option 2: Your own gateway in front of Vertex AI

If your team already runs an OpenAI-compatible gateway (for example, LiteLLM) that forwards requests to Vertex AI, connect the gateway instead of Google directly:

1. Get the gateway's base URL, the model names it exposes for Gemini, and a key.
2. Add it as a custom provider in the workspace `opencode.jsonc`.

See [Add a custom LLM or AI gateway](/start-here/connect-your-stack/add-a-custom-llm) for the config format.

## FAQ

<AccordionGroup>
  <Accordion title="Can I use Gemini in Harness for free?">
    Harness itself is free. Gemini usage is billed, or rate-limited, by Google according to the plan on your API key or Google Cloud project.
  </Accordion>
  <Accordion title="Is Vertex AI the same as Gemini Enterprise Agent Platform?">
    Yes. Google renamed Vertex AI to Gemini Enterprise Agent Platform. Harness still uses the provider IDs `google-vertex` and `google-vertex-anthropic`.
  </Accordion>
  <Accordion title="Does connecting Gemini also connect Gmail or Drive?">
    No. Model access and Google Workspace data are separate. To let the agent read Gmail, Calendar, or Drive, add an MCP server for that service; see [Add a custom MCP server](/start-here/connect-your-stack/add-an-mcp-server).
  </Accordion>
</AccordionGroup>
